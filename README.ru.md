## Команды

Все команды клиентские: на сервер ничего не отправляется.

| Команда             | Описание                                                                         |
|---------------------|----------------------------------------------------------------------------------|
| `/ts`               | Включить или выключить AutoSprint                                                |
| `/cc`               | Очистить чат                                                                     |
| `/copy <текст>`     | Скопировать текст в буфер обмена (используется Copy Chat Message)                |
| `/fov <10-110>`     | Установить FOV (значения вне диапазона обрезаются до границ)                     |
| `/tr <сообщение>`   | Перевести сообщение с русского на английский (видно только вам)                  |
| `/monkey`           | Включить или выключить детектор Murder Mystery (только Hypixel)                  |

## Chat Translator

### Перевод входящих сообщений

У каждого сообщения в чате появляется кликабельная кнопка **[T]**. Нажав на неё, 
сообщение будет переведено на русский (исходный язык определяется автоматически).
Результат виден только в вашем чате.

### `/tr` — перевод собственного сообщения

```
/tr Привет, это не моё
[tr] hi, this isnt mine
```

Результат оформляется так, как люди обычно пишут в чате:

- начинается со строчной буквы
- апострофы убираются (`it's` → `its`, `don't` → `dont`)
- точка в конце не ставится

Нажмите на результат, чтобы скопировать его в буфер обмена, затем вставьте в обычный чат.

### Как это работает

Запросы выполняются в фоновом потоке, поэтому игра не зависает. Сервисы пробуются
по очереди, пока один не ответит:

1. Google Cloud Translation API (необязательно, `OFFICIAL_API_KEY` в `Translator.java`)
2. Google Translate (`translate.googleapis.com`, `translate.google.com`)
3. Эндпоинт Google `clients5`
4. MyMemory (без ключа, около 5000 символов в день)

Если все сервисы недоступны, в чате выводится ошибка каждого из них, например:
`googleapis: HTTP 429; clients5: HTTP 429; mymemory: HTTP 429`.

> Бесплатные эндпоинты Google неофициальные и могут возвращать `HTTP 429`
> (слишком много запросов). В этом случае перевод автоматически переходит на MyMemory.

## Murder Mystery Mod

### Возможности

- **Подсветка в TAB-списке** — ник убийцы становится тёмно-красным
- **Уведомление в чате** — мод выводит имя убийцы в чат
- Поддержка режимов **Classic** и **Double**

### Как это работает

Каждый кадр мод проверяет игроков вокруг: держат ли они предмет со скином ножа.
Список игроков обновляется раз в секунду. Если нож обнаружен, игрок помечается
как убийца, подсвечивается в TAB-списке, а в чат выводится сообщение.
